A patch release of the open firmware and MCP server for the FNIRSI 1013D (Anlogic AL3A10 variant): the measurement
cards behave the same in every view. It needs the same FPGA bitstream as 0.3.0 to 0.4.2, **0x153F**, so you only
update the firmware on the card. Your calibration stays valid.

Documentation: <https://mikljohansson.github.io/fnirsi-1013d-mcp/> (install guide, the screens, the agent guide). The
0.3.0 notes describe everything this firmware does: <https://github.com/mikljohansson/fnirsi-1013d-mcp/releases/tag/v0.3.0>.

### What changed

- **Spectrum and Frequency response: "+N more" opens the rest.** Since 0.4.1 a tap on the measurement cards in the
  Scope view shows every selected measurement in rows above the bottom row. The Spectrum analyser and the Frequency
  response view still only counted the cards that did not fit. They now work the same way: tap a card to see all of
  them, tap "Show less" or any card to fold them again.
- **One setting for all views.** Expanded or folded is remembered, also after power-off, and applies to the Scope,
  the Spectrum and the Frequency response views together.
- A tap on a card in the expanded rows does not zoom or pan the spectrum behind it.

### Update from 0.3.0 to 0.4.2

1. Download `fnirsi_1013d-fw-0.4.3.bin` and `SHA256SUMS`, and check: `sha256sum -c SHA256SUMS --ignore-missing`.
2. Write the firmware to the card. With the MCP package: `fnirsi1013d-flash --image fnirsi_1013d-fw-0.4.3.bin
   --sha256 <hash> --persist` (it backs up the sectors it replaces). Or build the SD parts and write only the scope part
   with the SD tools, as the install guide describes. The bitstream stays 0x153F: no programmer needed.
3. Coming from 0.3.0, run the calibration wizard for 0.3.1's zero correction: both probes unplugged from the inputs and
   USB unplugged for the zero step, then each probe at x1 on the calibration post. From 0.3.1 or later nothing is needed.
4. MCP: the server is unchanged since 0.4.1; install the attached wheel if you are on an older one.

A new install follows the 0.3.0 steps with the 0.4.3 firmware file: <https://mikljohansson.github.io/fnirsi-1013d-mcp/guide/install/>.

### Known issues

- **The expanded rows cover the bottom of the plot**, in the Spectrum up to three rows with everything selected.
- **A tap just beside a measurement card still goes to the plot** and can change V/div, the time base or the span.
  Taps on a card do not.
- **A few pixels can remain between the trigger point and the H marker at 10 ns/div** where the edge is shallow at the
  trigger level.
- **Probe ground is not USB ground.** The probe ground clips sit on an internal reference about 1.24 V above the
  scope's USB ground. If the device you measure shares the PC's USB ground and a ground clip is on it, every trace
  shifts by about -1.2 V. Power the device from a battery or through a USB isolator, or leave the clip off for slow
  signals (`docs/agent-measurement-guide.md`).
- **One unit.** Everything was benched on a single AL3A10 unit.
- The other items listed for 0.4.2, 0.4.1, 0.4.0, 0.3.4, 0.3.3 and 0.3.1 are unchanged:
  <https://github.com/mikljohansson/fnirsi-1013d-mcp/releases/tag/v0.4.2>.
- **The firmware runs only with bitstream 0x153F**; other bitstreams show a banner.
