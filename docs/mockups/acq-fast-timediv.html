What the ACQ menu should offer faster than 50 ns/div

The scope samples at 200 MSa/s, so 20 ns/div holds four samples per division. Today the firmware requires ten, which leaves three permanently grey boxes. The reporter asks to allow 20 ns/div by hand, mark it, and drop the faster ones. Each panel below shows the menu, the top bar's ACQ chip and a 10 MHz square wave from the calibration post as that option would draw it.

Tap the time/div boxes in any panel. The sample rate follows as on the scope (3000 samples of memory).

Two decisions before any code

Where the exception applies

Only at 200 MSa/s, where no faster rate exists and the 30 MHz front end has already band-limited the signal. Or also when zooming into a stopped record at any rate, which is magnification of data already captured. The mock-ups show the first.

How it is marked

The mock-ups use orange text with an outline in the menu, an orange fill when chosen, and an orange time/div in the ACQ chip. Orange is already the trigger chip's frequency colour, so a different hue or a small tag ("x2.5 zoom") may read better.
